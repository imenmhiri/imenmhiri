## Engineering & Internship Projects

> These were built inside companies. The source code is internal and under their confidentiality, so it is not published here — but I'm glad to walk through the architecture, the trade-offs and the decisions behind each one.

### AI-Based WAF Optimization — Continuous Learning Pipeline
*Final-year engineering project · SECURAS Technologies*

An end-to-end pipeline that turns raw Web Application Firewall logs into a continuously retrained detection model.

- Streamed and transformed WAF logs with **Kafka** and **Flink**, persisting to **HDFS**
- Orchestrated ingestion, feature preparation and retraining as scheduled **Airflow** DAGs
- Tracked experiments, metrics and model versions in **MLflow** so every retrain is reproducible
- Packaged the full stack with **Docker Compose** for one-command local runs

`Kafka` `Flink` `HDFS` `Airflow` `MLflow` `Python` `MongoDB` `Docker`

### Weather Forecast Application — Full-Stack & CI/CD
*Internship · CED*

- Built an **Angular** frontend against an **ASP.NET Core** REST API backed by **SQL Server**
- Containerized frontend, API and database with **Docker Compose**
- Automated build, test and deployment through **Azure DevOps** pipelines, removing manual releases

`Angular` `TypeScript` `C#` `ASP.NET Core` `SQL Server` `Docker` `Azure DevOps`

### Multi-Company HR Onboarding Platform

A multi-tenant onboarding application where each company's data stays strictly isolated.

- Modeled per-company onboarding journeys on **Next.js** + **Supabase**
- Automated HR workflows with **n8n** and added **LLM**-assisted steps
- Wrote row-level isolation tests to prove no cross-tenant data leakage

`Next.js` `TypeScript` `Supabase` `n8n` `Docker` `LLMs`
